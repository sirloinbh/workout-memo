- #140: 사용자가 선택지는 추천안으로 진행하라고 맡겼다. 달력 주를 쓰는 코드가 모두 월요일 기준이고 바꾸면 지난 주간 값이 달라져 예외를 추천안으로 택했다. 근거는 이슈 코멘트에 있다.

- 전체 `npm run check`가 또 메모리 부족으로 중단됐다. 부분 검사와 PR CI로 확인했다.
- 패키지 설치 명령은 허용된 `npm ci`만 실행했다. 새 패키지는 없다.
- `npm audit --package-lock-only`(마감 시점): `frontend`, `backend`는 0건이다. 루트는 high 13건이고 `@lhci/cli` 쪽 개발 도구 경로와 루트 `node_modules/zod` 3.25.76이 포함된다. #148의 완료 기준은 아직 채우지 못했다.
- `docs`와 `README.md`에 `NODE_AUTH_TOKEN` 안내가 없다. 닫힌 PR #146의 브랜치에만 있고, 그 기록에는 서버 `.env`에 없으면 배포 이미지 빌드가 실패한다고 적혀 있다.
