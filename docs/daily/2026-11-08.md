## 결정과 발견

- 세 agent가 같은 `style.css`·시각 기준선을 동시에 바꿔 병합 순서가 겹쳤다. 병합 규칙: head CI(e2e-visual 포함) 통과, CLEAN, 갈라진 뒤 main이 `style.css`·`components/**`·`e2e/**`·`package*.json`·`shared/**`를 바꾸지 않았을 때만 그대로 병합한다. 아니면 `origin/main`을 병합하고 CI를 다시 돌린다. 병합 직전에 `git merge-base --is-ancestor origin/main HEAD`로 따로 확인한다.
- #231: `.legacy button`의 44px 규칙이 공통 `Checkbox` 상자를 키웠고, 상자를 되돌리면 `::after` 누름 영역이 42px였다. `pointer-coarse:min-h-4 pointer-coarse:min-w-4 pointer-coarse:after:-inset-[15px]`로 맞췄다(#233 휴식 요일도 같음). 터치 e2e가 체크박스 상자 크기도 확인한다.
- #232: 리뷰가 좁은 화면 칸 겹침, legacy `.modal label` 겹침, 숫자가 아닌 값 때문에 초안 전체가 버려질 수 있는 문제를 잡았다. 총중량 0.25kg 단위 검사는 #234로 분리했다.
- #233: 운동 행 빈칸을 고쳤다. 제안된 `grid-flow-dense`는 탭 순서가 화면 순서와 달라져 쓰지 않았다.
- #125(#241): 휴대폰(768px 미만)에서만 상세로 포커스·스크롤을 옮기고, "운동 목록"으로 돌아오면 고른 운동 버튼에 포커스를 돌려준다. 넓은 화면은 포커스가 목록에 남는다. 고정 데이터 기준 세로 길이는 390px 2,679→1,090px, 1280px 2,291→1,140px이다.
- 시각 기준선은 모두 CI `visual-baselines` 이미지를 직접 본 뒤 갱신했다.
- 운영 반영: #239 확인 때 #240이 이미 병합돼 있어, CSS `BUn0QHaA`가 #239 단독 빌드인지 구분하지 못했다. #241 병합 직전(16:12) 운영 CSS는 `C4wYKDIG`였다. #231·#235·#232·#236은 각자의 확인 기록이 없지만 확인된 빌드보다 먼저 병합됐다.
