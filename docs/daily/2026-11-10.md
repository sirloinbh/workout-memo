## Decisions and findings

- [#124](https://github.com/sirloinbh/workout-memo/issues/124) user decisions
  - The input UI is an app-specific Combobox (WAI-ARIA, no new package, 44px touch). The request for a central shared Combobox is [project-standards#437](https://github.com/sirloinbh/project-standards/issues/437).
  - The suggestions come from a new API.
  - A similar name (differing only in spaces or letter case) gets a notice only and is not replaced automatically.
  - Choosing body parts in exercise analysis has no exercise name input (you pick a recorded exercise), so it is not an autocomplete target.
- The first #258 sync was missing a space between shared `Checkbox` classes, so CI failed. The merge was held, [project-standards#433](https://github.com/sirloinbh/project-standards/issues/433) was registered centrally, and the fixed sync was merged.
- Found in the Combobox review
  - If the list name contains the input name ("운동명", exercise name), Playwright `getByLabel` matches two elements by partial match and the e2e breaks. The list name is "이전에 쓴 이름" (names used before).
  - Clicking a suggestion inside a `<label>` passed the click to the input and reopened the list.
  - The edit window (Radix Dialog) takes Esc in the document capture phase, so the list blocks it first in the window capture phase, only while it is open.
- Moving the save status line (`role="status"`) into a different wrapper only while saving recreates it, and a screen reader may miss it (#270 review). The wrapper always stays and only the spinner is added and removed.
- Running the whole frontend test suite at once makes one long test in `routines.test.tsx` hit the 15-second limit. It passes when run alone (the same in #270 and #273).
- `TEST_DATABASE_URL` in this PC's shell points to another project's DB. This app's DB integration tests were checked in CI (#273 `verify`).
- #109 PWA was assigned to agent1. `sw.js`, the manifest, `offline.html`, and `nginx.conf` are centrally managed files. User decisions
  - When a new version takes over, show only a notice and a [Refresh] button; do not refresh automatically.
  - Offline keeps `offline.html`, and the save failure message changes to a note that the draft is kept. The app shell cache waits until after #106 and #107.
  - Keep the hand-written `sw.js`; do not use `vite-plugin-pwa`.
  - Check installability, service worker registration, and offline navigation once on a localhost production build and record it. Real device and production checks come after #106.
  - `/api/` is not cached (so it does not clash with the #107 401 handling).
