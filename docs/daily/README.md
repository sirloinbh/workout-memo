# 일일 작업 기록

작업일별 총정리를 `YYYY-MM-DD.md`로 누적한다. 날짜는 Asia/Seoul 기준이다.

## 작성·보존 규칙

- 주 에이전트는 작업일의 마무리 또는 사용자 총정리 요청 시 해당 날짜의 기록을 작성·갱신한다.
- 같은 날의 추가 작업은 기존 파일에 추가하고, 다음 작업일에는 새 날짜 파일을 만든다. 작업이 없는 날은 빈 기록을 만들지 않는다.
- 주요 작업, 실제 검증 결과, 이슈·PR, 그날 확인한 완료·대기·차단 상태를 간략히 적는다. 실행하지 않은 작업은 완료로 적지 않는다.
- 과거 날짜의 상태를 오늘 상태로 덮어쓰지 않는다. 사실 오류를 바로잡을 때는 정정 사유를 남긴다.
- 새 기록을 만들면 아래 목록의 맨 위에 추가한다. 최신 할 일은 [next-steps](../next-steps/README.md)에서 관리한다.
- 정해진 시각에 자동 생성하는 스케줄러는 없다. 기존 이슈·커밋별 [변경 기록](../changes/)도 계속 유지한다.
