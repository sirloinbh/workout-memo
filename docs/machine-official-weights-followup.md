# Machine official base weight follow-up research (#87)

- Issue: https://github.com/sirloinbh/workout-memo/issues/87 (earlier research: [machine-official-weights.md](machine-official-weights.md), #29)
- Checked on: 2026-10-21 (Asia/Seoul)
- App use: `database/migrations/013_official_weights_followup.sql`. It updates only the rows left as `unverified` in #29, by the same key (brand, lineup, model, setting), and adds no new reference rows.

## Criteria

- We follow the #29 criteria as they are (only official material is accepted, unconfirmed is NULL, `kg = lb × 0.45359237` rounded to the second decimal, and `unspecified` if there is no official wording).
- Manufacturer sites
  - Hammer Strength: the Life Fitness catalog (`lifefitness.com`)
  - Arsenal Strength: `myarsenalstrength.com`. The `arsenalstrength.com` we fetched in #29 is an unrelated gym site, so we had not found official material.
  - The Arsenal product pages say "Starting Weight" and give no kg figure. So we set `official_item_name` to `Starting Weight` and leave the manufacturer kg figure empty.
- **Unofficial values (user decision: show them separately as "reference (unofficial)")**
  - For the rows with no official value (Assisted Nordic Ham, Newtech 온힘 (Onhim)), we also could not find specific figures from retailers or communities. So this time we did not store or show any unofficial value.
  - The 3 cases where a retailer (Performaxx) value matched the official value are left only in the notes.
  - If unofficial values are added later, they go in a separate field with a "reference (unofficial)" label and are not mixed with official values.

## Result summary

- Rows researched, 조사 행 수: 28
- Official value confirmed (`verified`): Hammer Strength 15, Arsenal Strength 11
- Still unconfirmed (`unverified`): 2 rows
  - Hammer Strength Plate Loaded Assisted Nordic Ham: the official value is an assistance load (Starting Assistance).
  - Newtech 온힘 (Onhim) lineup: the official detail has only the maximum weight stack.
- Values that need a judgment
  - Abdominal / Oblique Crunch has the official wording "25 lb (11 kg) + 10% of user weight". We set only the fixed part, 25 lb, as the value and left a note.
  - T-Bar Row and Glute Drive have no basis in the US catalog (`unspecified`). The Australian site writes the same figures as "per arm", but the figures are the same, so we did not treat it as a `conflict`.
- We do not change the user's machine base weights or the total weight of past sets (the #29 principle). Only the display of the official reference value linked to a machine changes.
