# Machine official base weight (starting resistance) research

- Issue: https://github.com/sirloinbh/workout-memo/issues/29
- Checked on: 2026-10-19 (Asia/Seoul)
- App use: the `official_machine_weights` reference table in `database/migrations/009_official_machine_weights.sql`
- Follow-up research (#87, 2026-10-21): [machine-official-weights-followup.md](machine-official-weights-followup.md). The table below is the result at the time of #29 (009), and 26 of the 28 unconfirmed rows were updated with official values in 013.

## Criteria

- **Base weight = the starting resistance (Starting Resistance) published by the manufacturer**, that is, the resistance with no plates loaded. We do not use the product weight, shipping weight or maximum load.
- **Only official material is accepted.** We used only the manufacturer's official product pages, catalogs and manuals, or official manufacturer answers that can be recorded. Retailers, blogs, communities and user-measured values are not adopted as official values even if they have a number; we recorded `NULL` and the reason.
- **Unconfirmed is NULL, a confirmed 0 is 0.** No official 0 kg value was found in this research.
- **Unit conversion:** we keep the original value and unit, and compute `kg = lb × 0.45359237` rounded to 2 decimal places (for example 7 lb → 3.18 kg). A kg figure that the manufacturer also gives is kept as is in `manufacturer kg figure`. The manufacturer's kg figure can differ from the converted value because of a different rounding method (for example 6 lb → converted 2.72 kg, manufacturer figure 3 kg).
- **Basis:** `per_arm` is when the official wording has per arm/per workarm/per work-arm. If there is no such wording we do not guess and set `unspecified`. There is no row in this research whose combined total (`combined`) was confirmed by the official wording.
- **Status:** `verified` (official value confirmed), `unverified` (official value not confirmed, value NULL), `conflict` (possible disagreement between official sources. The value follows the official page we fetched and we did not resolve it arbitrarily).
- If the generation, version or setting differs, it gets a separate row. For the Belt Squat, the official page publishes the starting resistance per anchor position, so we recorded it as 4 rows.

## Research method and scope

- Hammer Strength: from the Hammer Strength Plate-Loaded list in Life Fitness's official US catalog (`https://www.lifefitness.com/en-us/catalog/strength-training/plate-loaded`) we confirmed 41 current models. For 25 of them we fetched the specification table of the product page directly and recorded the `Product Code` and `Starting Resistance` items. The other 16 could not have their product pages fetched because of the research cap (about 40 web fetches), so we left them as NULL. The 12 Life Fitness brand Plate Loaded models on the same page are outside the scope (Hammer Strength) and were excluded. We did not research other Hammer Strength lines such as selectorized.
- Arsenal Strength: we could not find an official manufacturer product page or catalog. `arsenalstrength.com` was an unrelated gym site when fetched on 2026-10-19, and `www.arsenalstrength.net` failed DNS resolution. The Reloaded model names and starting resistance figures were found only in an Australian retailer (Performaxx) listing, so we did not adopt them as official values. The model list is also based on the retailer, so it is not guaranteed to be the official current list.
- Newtech (뉴텍) 온힘 (Onhim): the official site `www.ntws.co.kr` (Korean and English) returned HTTP 403 to the automated fetch. Public search showed only Newtech's M Torture (plate) and Advance (pin) lines, so we could not confirm the 온힘 (Onhim) lineup and model list from official material. We did not mix in values from other Newtech lines.
- Discontinued and older models are not included because we could not confirm them from official material.

## Summary

- Rows researched, 조사 행 수: 56 (53 models; includes the 4 Belt Squat anchor rows)
- Official value confirmed: 28 rows (25 models). Of these, 1 row is `conflict` (Plate Loaded Seated Biceps)
- Official value unconfirmed (NULL): 28 rows — Hammer Strength product page not fetched 16, Arsenal Strength 11, Newtech 온힘 (Onhim) 1
- Unresolved disagreement: Seated Biceps is marked `4 lbs (2 kg)` with no basis on the en-us page. In the search result summary the en-eu page looked like `4 lbs (1.8 kg) per workarm`. We did not fetch the en-eu page directly.
- Official wording that needs attention: Hack Squat (125 lb) and Pendulum-X Squat (81 lb) are marked per arm on the official pages, so we recorded them as is. What this means for the structure needs confirmation from the manufacturer.

## How the app uses it

- 009 adds `Newtech` to the brand list idempotently (`brands.name` UNIQUE, `ON CONFLICT DO NOTHING`). The stored and displayed name is unified as the single `Newtech`, the same as the `brand` value in the reference table. The Korean alias (뉴텍) is used only in this document, and the screen also shows `Newtech`. When you register a Newtech machine, the 온힘 (Onhim) reference row appears in the choices as "official value unconfirmed".
- The official reference values are in a separate table from the user's machine base weight. On the machine register and edit screens you can pick and link a reference value of the same brand, and the machine library and the machine choice list in the log show it as "official reference value" together with its basis and source.
- Linking a reference value does not change the base weight input value, and it is not applied automatically. A set's weight is still the total weight the user entered, and the total weight of past logs does not change.
- A per-side value is not the sum of both sides. Whether to use it as the base weight is up to the user, who checks the machine's structure.
